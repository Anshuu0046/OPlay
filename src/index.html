Windows settings

Global Optimize enables Game Mode and disables background game recording. OPlay saves previous values before writing and checks them afterwards.

Disabling recording affects Xbox Game Bar capture. Some games need a restart to pick up preferences.

There is no universal kernel or memory boost switch. OPlay uses supported Windows settings and reports real telemetry. FPS gains require a game benchmark.

Driver offset control

GPU & VRAM overclock / underclock

Set the NVIDIA driver's P0/P2 frequency offsets. Positive values overclock; negative values underclock. These are frequency offsets, not voltage controls. The driver range is not a tested stable range.

Reading driver offsets…

Windows administrator approval is needed for writes. Original offsets are backed up before changes. The helper restores OPlay's offsets on disconnect, on exit, or at 85°C. New writes are blocked from 80°C. Avoid running another tuning app simultaneously.
Voltage / frequency curve

GPU undervolting

Choose a voltage point and target clock. OPlay edits that point and flattens the higher-voltage curve, then verifies the driver read-back. Actual operating voltage remains controlled by the driver; a flat curve is not a hard voltage limit.

Reading the NVIDIA V/F curve…

Enable GPU controls above first. Curve and offset sessions are separate; restore before switching. Backups, the 20-second watchdog and 85°C rollback apply to curve edits. Writes are currently verified for Ampere GPUs. Test your games before relying on a new curve.
NVIDIA calibration

Automatic GPU tuning

Run NVIDIA's own stability scanner through its installed Performance panel. Calibration can take tens of minutes or longer; leave the PC idle until it finishes. OPlay restores and disconnects its manual offset helper before the scan so the two tuners cannot compete.

Reading NVIDIA calibration status…

Keep the PC on AC power and idle during scanning. NVIDIA's own confirmation may be required. English NVIDIA App accessibility controls are currently supported; its interface must remain open. Vendor results persist in NVIDIA App and are separate from OPlay's session offsets.
Hardware limit

Hardware capabilities

Driver-accepted offsets are not proof of stability. Use NVIDIA calibration for the GPU and test your own games before keeping higher offsets. CPU and system-RAM frequency writes require supported firmware controls that OPlay has not found on this system.
